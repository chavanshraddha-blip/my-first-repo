Internship Milestones (Weeks 1–7)

Week 1
Flask Setup & Architecture

Application factory pattern, Blueprints, SQLAlchemy ORM, Flask-Migrate integration, and SQLite setup.

Week 2
User Authentication

Secure registration, login, logout, password hashing with Werkzeug, Flask-Login session management.

Week 3
Post CRUD & Rich Text

Full CRUD operations, Category & Tag relationships, Flask-WTF forms, CSRF protection, and Quill rich text editor.

Week 4
Frontend & Pagination

Jinja2 template inheritance, responsive Bootstrap 5 interface, author profiles, and pagination.

Week 5
Commenting System

Authenticated commenting, comment management, user avatars, and authorization controls.

Week 6
Search & Filtering

Full-text search over titles and contents, multi-criteria filtering by category and tag, query preservation.

Week 7
Testing & Deployment

Automated test suite using pytest, Gunicorn WSGI server setup, Docker containerization, and production hardening.
